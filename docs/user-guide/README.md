# User guide

Start with [first login](../getting-started/first-login.md), then follow [a normal working day](daily-workflow.md). Your sidebar and tools depend on your role, the active CRM campaign, its forms, and enabled telephony features.

| Task | Guide |
| --- | --- |
| Start and finish a shift | [Daily workflow](daily-workflow.md) |
| Understand campaign and customer context | [Campaigns and leads](campaigns-and-leads.md) |
| Save customer information and find it again | [Forms and records](forms-and-records.md) |
| Call a customer and record the outcome | [Calls and dispositions](calls-and-dispositions.md) |
| Arrange a return call | [Callbacks](callbacks.md) |
| Record breaks and review attendance | [Attendance](attendance.md) |
| Interpret performance figures | [Reports](reports.md) |
| Read alerts and messages | [Notifications](notifications.md) |

Agents normally use **Dashboard**, **Call History**, **Attendance**, **Agent Screen**, and **Campaign Forms**. Team Leaders, Admins, and Super Admins also have [administration tools](../admin/README.md). A hidden or disabled control is not necessarily a fault: check your role and the organization's configured features before asking for access.

These guides describe checked-in behavior, not a verified connection to your phone system. They do not establish that a particular deployment has working calling, recordings, live reports, or background jobs. For problems, collect the page, campaign, approximate time, and exact visible error, then use [troubleshooting](../operations/troubleshooting.md). Keep credentials and customer details out of ordinary support messages.
