## Framework and package routes

`bootstrap/app.php` declares Laravel's `/up` health route and loads broadcast channel registration. Laravel registers `/broadcasting/auth` for channel authorization; Echo expects this path with the application base prefix. Sanctum may register `/sanctum/csrf-cookie`, and Horizon/package routes depend on their provider/configuration. These are not explicit declarations in the three route files above. Inspect an authorized isolated runtime route registry before proxy allowlisting or treating this source inventory as a complete deployment exposure list.

`/api/client-errors` currently only returns `{ "ok": true }`; it does not persist or forward the submitted report. Public operations insights endpoints and telephony health endpoints can do backend work; do not invoke them as a documentation check.
