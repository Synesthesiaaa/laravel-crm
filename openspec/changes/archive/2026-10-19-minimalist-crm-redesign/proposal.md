## Why

The CRM's repeated boxed sections, saturated accents, and icon-only search compete with daily call-center work. Users need a quieter interface with clear navigation and immediately discoverable common actions.

## What Changes

- Apply taste-skills minimalist guidance to the authenticated shell, shared controls, dashboard, and sign-in surface.
- Default new sessions to light mode while retaining saved light/dark preferences.
- Make global search visible at every viewport, clarify campaign context, and retain accessible mobile navigation even after desktop collapse.
- Reduce ornamental borders, shadows, icon tiles, and dashboard emphasis without changing operational data or permissions.

## Capabilities

### New Capabilities
- `minimalist-crm-interface`: Consistent neutral presentation, discoverable search, campaign context, and responsive navigation.

### Modified Capabilities
- `login-experience`: Replace the Signal Magenta primary action with a neutral action, use the shared flat materials, and default new sessions to light while respecting saved preferences. Authentication behavior and branding remain intact.

## Impact

Blade layouts/components, shared CSS, dashboard presentation, login theme initialization, focused feature tests, and browser verification. No database, API, dependency, or deployment changes.
