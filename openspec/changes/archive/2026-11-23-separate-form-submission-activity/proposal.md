## Why

The dashboard combines form submissions in shared charts, which makes an individual form's activity harder to read and compare across time periods.

## What Changes

- Show submission activity for one form in the active campaign at a time.
- Let users select the form and view the last 24 hours, the current week, or the current month.
- Provide an expandable table of submission counts for the selected form and period.

## Capabilities

### New Capabilities

- `dashboard-form-activity` covers the dashboard's form and period selectors, chart, and submission counts table.

### Modified Capabilities

## Impact

The campaign dashboard uses its existing submission trends and chart library. The change requires no schema or API changes.
