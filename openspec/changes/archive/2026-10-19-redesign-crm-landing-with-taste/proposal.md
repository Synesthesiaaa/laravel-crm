## Why

The public landing page repeats long feature descriptions in both the hero and its preview. Redesign it using the installed Taste skill so visitors can understand the call-center workflow quickly and enter the existing CRM.

## What Changes

- Introduce a focused asymmetric hero with a clearly labeled, illustrative agent workspace.
- Present the lead-to-call-to-follow-up workflow and role-scoped capabilities in concise sections.
- Preserve configurable branding, existing theme persistence, named sign-in routes, keyboard access, and responsive behavior.
- Keep motion restrained and respect reduced-motion preferences.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `public-landing-experience`: Define an explicitly illustrative product preview and persistent accessible theme selection.

## Impact

Public welcome Blade template, scoped landing CSS, existing landing feature tests, and public landing specification. No backend, schema, authentication, or dependency changes.
