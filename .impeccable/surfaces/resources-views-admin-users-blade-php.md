# User Access CSV import extension

Operate mode. Extend the existing User Access page for a Super Admin creating a large staff directory. Keep the individual user form, paginated staff table, permissions, and telephony widgets.

## Direction contract

THESIS: A staged operational task: upload, review real counts, explicitly create eligible users. Preserve single-user access beside bulk creation.

OWN-WORLD: Existing application CSS variables, flat admin panels, form labels, primary/secondary controls, and restrained state text in both themes. No new palette or display font.

STORY: The operator supplies a CSV, sees what will happen without account writes, chooses whether to create eligible accounts, and can return to persistent progress or download issues.

FIRST VIEWPORT: The existing User Access header leads into one inline import panel: template link in its header, labelled file input and role opt-in side by side on desktop, upload/preview action beneath, then conditional progress and counts. Individual-user creation remains below.
